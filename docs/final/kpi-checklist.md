# Ведомость готовности и проверки KPI

| Требование | Статус на 12.10.2026 | Основание / следующий шаг |
|---|---|---|
| Новые коэффициенты ёмкости | Проверено в выбранной трактовке | 360×0,35×0,10 = 12,6 → 13; Decimal-скрипт |
| Онлайн-арифметика | Проверена | 7 сочетаний, S/S−1, Erlang B |
| Один общий LTE-пул | Кандидат | 13 UE/пул без CA; нет запаса на ещё одного целого UE |
| DWG / масштаб | Прочитан и проверен | INSUNITS=4; DXF audit 0; рисунок сверён с PNG |
| Антенны / трассы | Проектный вариант | 48 точек; координаты меток, крепления не подтверждены |
| ВК | Не определена | Предложенная точка в районе 118; это не утверждённая аппаратная |
| Обслуживаемая площадь | Не определена | Экспликация 2097,06 м²; помещение 89 не локализовано |
| RSRP 5/10/15/20 м | Рассчитано условно | 576 сочетаний антенна/полоса/расстояние; P1, n=2,5 |
| RSRP >−90 на 95% | Не проверено | Нет подтверждённой нормировки пилота и маски/классификации препятствий |
| Худшая ветвь 20 м без стен | Не проходит выбранный сценарий | Около −98,64 дБм B7 после замены длинных участков на 7/8; площадь не оценена этим тестом |
| RSRQ >−12 на 80% | Не проверено | Нужны RSSI, загрузка и внешние помехи |
| SINR ≥17/7/1 на 40/80/95% | Не проверено | Единицы дБ — допущение; нет внешнего частотного/помехового плана |
| LTE Best Server | Один обслуживающий пул | Не путать сильнейшую антенну со второй ячейкой |
| DCS RxLev >−85, C/I >20 на 95% | Не проверено | Мощность BCCH/TRX, частоты и помехи не заданы |
| MIMO 2×2 | Сохранена структура двух ветвей | Развязка, корреляция и фактические CQI/RI не подтверждены |
| UL | Не проверено | Нужны NF, чувствительность, мощность UE и бюджет |
| Три оператора | Предусмотрены входы | Нет нагрузок/мощностей/полос двух других; не заявлять их ёмкость |
| Изоляция / PIM / мощности | Не проверено | Нет условий PIM и допустимой мощности компонентов |
| Пожарное исполнение | Различие документов | XLSX: огнестойкое безгалогеновое; PDF: PE-модификации |
| Удалённая регулировка | Не выполнена пассивной схемой | Требуемых модулей нет в перечне |
| XLSX спецификация | Подготовлен черновик | Количества из структуры, не закупочное подтверждение |
| Презентация | Подготовлен черновик | Свободный формат разрешён; нужен шаблон и данные автора |

Итог: вычислительные и документальные заготовки воспроизводимы, но выполнение KPI и полное соответствие финальному ТЗ не установлены. Отсутствующие данные не заменяются выдуманными измерениями или паспортами.
