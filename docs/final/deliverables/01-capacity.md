# Исходные данные

Расчёт выполнен для сети МТС на этаже ТРК «Эльбрус» площадью 2100 м². Новые параметры RRC Connected и buffer users последовательно определяют число устройств, между которыми распределяется радиоресурс.

| Параметр | Значение |
| --- | --- |
| Посетители в ЧНН | 500 |
| Доля МТС | 60% |
| Рост числа пользователей 4G | 1,2 |
| Avg RRC conn UE | 35% |
| Buffer users of RRC | 10% |
| Полезная скорость DL | 8 Мбит/с на UE |
| Полосы B3 / B1 / B7 | 20 / 15 / 10 МГц |
| Режим LTE | FDD, MIMO 2×2 |

В расчёте приняты доля 4G-устройств f₄G=1, эквивалентная полезная спектральная эффективность η=3,1505922 бит/с/Гц и загрузка радиоресурса u=0,8. CA для базовой конфигурации не требуется.

\[\eta=0{,}84\cdot(6\cdot567/1024)\cdot1{,}6\cdot0{,}80\cdot0{,}90\cdot0{,}98.\]

Коэффициент 0,84 определяется сеткой PRB; 6×567/1024 — эквивалент CQI 11; 1,6 — средний ранг: 60% ресурсов rank 2 и 40% rank 1. Доли 0,80 / 0,90 / 0,98 учитывают RE данных, повторы HARQ и протокольные заголовки. Это сохранённые допущения онлайн-модели; MIMO и накладные расходы повторно не умножаются.

# Одновременная нагрузка

\[N_{4G}=500\cdot0{,}60\cdot1{,}2=360\ \text{UE}.\]

\[N_{RRC}=360\cdot0{,}35=126,\qquad N_{buffer}=\lceil126\cdot0{,}10\rceil=13\ \text{UE}.\]

\[D_{DL}=13\cdot8=104\ \text{Мбит/с}.\]

Произведение 35%×10%=3,5% заменяет прежнюю оценку одновременности 80%. Повторное умножение на 80% не применяется, поскольку обе модели описывают одновременный спрос на данные. Количество устройств округляется вверх до расчёта требуемого трафика.

# Ёмкость трёх несущих

\[C_j=B_j\eta u,\qquad m_j=\left\lfloor\frac{C_j}{8}\right\rfloor.\]

| Несущая | Полоса, МГц | Cj, Мбит/с | UE по 8 Мбит/с |
| --- | --- | --- | --- |
| B3 | 20 | 50,4095 | 6 |
| B1 | 15 | 37,8071 | 4 |
| B7 | 10 | 25,2047 | 3 |

Суммарная полезная ёмкость составляет 113,4213 Мбит/с. Без CA обслуживаются 6+4+3=13 устройств. Распределение 6/4/3 требует 48/32/24 Мбит/с на соответствующих несущих. Остатки ресурса разных несущих не объединяются для одного устройства без CA.

# Выбор числа секторов

Принят один общий LTE-сектор с несущими B3/B1/B7. Для единственного общего пула k(1)=1: пространственного перекоса между отдельными секторами нет. Для S>1 сохраняется k=1,10 и проверяется условие ⌈kN/S⌉≤m, где N — число активных UE, S — число секторов, m=13 — вместимость сектора. При сохранении k=1,10 также для единственного сектора требуются два сектора.

| Показатель | Онлайн-этап | Финальное решение |
| --- | --- | --- |
| Одновременность | 80% | 35%×10% |
| Расчётное число UE | 288 | 13 |
| Спрос DL, Мбит/с | 2304 | 104 |
| UE на сектор без CA | 13 | 13 |
| Секторы при прежнем k=1,10 | 25 | 2 |
| Принятый вариант, k(1)=1 | — | 1 |

Изменение спроса снижает число секторов с 25 до 2 при прежнем правиле. Выбор одного сектора дополнительно учитывает отсутствие межсекторного перекоса внутри общего пула. Четыре группы DAS распределяют сигнал этого сектора и не создают дополнительную ёмкость.

# Голосовая нагрузка DCS

Голосовая нагрузка: 500×0,60×0,025=7,5 Эрл. Рост 1,2 относится к 4G и к голосу не применяется. Приняты два TRX и 14 каналов TCH/F. Вероятность блокировки по Erlang B составляет 1,1421%, что ниже 1,5%. Распределение служебных временных интервалов соответствует принятой модели онлайн-этапа.

# Условия эксплуатации расчётной конфигурации

Вместимость 13 UE относится к принятой эффективности и загрузке. Терминалы должны поддерживать соответствующие диапазоны; балансировка обеспечивает распределение 6/4/3. Резерв для четырнадцатого UE без CA отсутствует. Пиковая нагрузка оценивается отдельно от среднего значения RRC.
