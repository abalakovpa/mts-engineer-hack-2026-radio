# Воспроизведение рабочих результатов

Из корня репозитория, Python 3.12:

```sh
python3 scripts/final/calculate.py
MPLCONFIGDIR=/tmp/radio-mpl python3 scripts/final/build_project.py
python3 scripts/final/validate.py
```

Зависимости зафиксированы в requirements.txt. В текущей машине они уже доступны. В новой среде при необходимости создать отдельное virtualenv и установить `python -m pip install -r scripts/final/requirements.txt`; исходные DOCX/DWG/XLSX/PDF/PNG не редактируются.

Для повторного извлечения CAD см. `design/final/README.md` и `extract_cad.py`. Генерация проекта использует уже сохранённый compact JSON и не требует конвертера при каждом запуске. Производные файлы перечислены в `docs/final/design-project.md`; их не следует редактировать вручную вместо входов генератора.

`calculate.py` использует Decimal для дискретных расчётов. `build_project.py` строит предложенную топологию, выбирает группы по длинам сети, создаёт схемы, XLSX и PPTX. Расчётные оценки компонентов явно заданы в скрипте и документах; это не скрытые паспортные данные. Диагностическое поле без стен не является картой подтверждённых KPI.

`validate.py` проверяет неизменность исходников архива, численные результаты, дерево ветвления, длины, количества в XLSX, RF-точки и структуру презентации. Неуспешный RF-сценарий отражается в отчёте: отсутствие assertion на KPI не означает, что KPI выполнены.
