## Расчётный результат и ограничения

Новые доли RRC/buffer дают 360×35%×10%=12,6 → **13 пользователей**,
спрос **104 Мбит/с**. Один общий LTE-пул B3/B1/B7 — кандидат при принятых
эффективности, балансировке и k(1)=1; запаса на 14-го пользователя без CA нет.
При сохранении прежнего коэффициента перекоса получается два сектора.

В проекте **32 In06**, четыре группы распределения и две независимые RF-ветви.
Установленный коаксиал двух ветвей — **1403,72 м**; закупочно **1366 м 7/8**
и **179 м 1/2**, с резервом 10%. Позиции и классы мощности заданы в
[project-input.json](design/final/project-input.json).

В условной модели P1 RSRP при n=3 проходит на **96,48 / 96,45 / 96,37%**
площади для B3/B1/B7; с закрытыми проёмами — **96,12 / 96,02 / 95,85%**.
n=3 и запас 3 дБ проверены отдельно. P2 не проходит 95%; RSRQ/SINR/C/I/UL,
монтажная и закупочная готовность не подтверждены. Пассивная схема
не выполняет требование удалённого регулирования.
