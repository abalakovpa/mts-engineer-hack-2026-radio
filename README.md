# МТС Engineer Hack 2026 — кейс «Радио»

**Автор:** [Павел Абалаков](https://github.com/abalakovpa).

Расчётное решение indoor-системы для первого этажа ТРК «Эльбрус»: DCS-1800,
LTE B3/B1/B7, MIMO 2×2, площадь 2100 м². Подготовлены пять артефактов:
три технических PDF, ведомость оборудования и презентация на официальном
шаблоне организаторов.
