# Данные текущего расчёта покрытия

[Описание модели](../../../docs/final/coverage-review.md),
[геометрия и чувствительность](../../../docs/final/reserve-review.md).

| Файлы | Назначение |
| --- | --- |
| area-model.json, rooms.geojson, area-audit.csv | Контуры, препятствия, веса и сверка площадей |
| area-model.png | Визуальная проверка геометрии |
| coverage-report.json, coverage-scenarios.csv, room-coverage.csv | 39 сценариев и номинальные доли по группам |
| rsrp-*.png | Карты текущего проекта: номинал, n=3 и запас |
| validated-fields.npz | Координаты, веса, номинальные поля и поля n=3 для проверки |
| resolution-0.5.json | Контроль сетки 0,5 м |
| geometry-control.json | Проверка текущей схемы с коротким стыком 0,15 м |

Кэши propagation-*.npz генерируются локально и исключены из Git.
Доли относятся к 2100 м² и весам экспликации; неизвестная площадь
считается непрошедшей. Данные являются результатами модели, не измерениями.
