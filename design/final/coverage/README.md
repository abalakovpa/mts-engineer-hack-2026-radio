# Производные данные покрытия

Модель и результаты описаны в [coverage-review.md](../../../docs/final/coverage-review.md).

- area-model.json / rooms.geojson / area-audit.csv — производная геометрия, материалы-допущения и сверка площадей.
- baseline-candidate.json — неизменённый начальный проект 48 антенн для сравнения.
- options-*.json / screening-selection.json — предварительный отбор, не окончательные маршруты.
- position-proposal.json — локальные предложения двух переносов; поле adopted=false означает, что сам поисковый скрипт не изменяет проект. Переносы отдельно внесены в project-input.json и полностью проверены.
- before-relocation-report.json — результат сетки 0,25 м до переносов.
- propagation-*.npz — кэш лучей с отпечатками геометрии и координат. Содержимое может обновляться при смене проекта; старые доли сохраняются в отчётах сравнения.
- coverage-report.json / coverage-scenarios.csv / room-coverage.csv — итоговые сценарные результаты текущих реальных ветвей.
- validated-fields.npz — точки, веса и номинальные поля трёх частот для независимой численной проверки.
- resolution-0.5.json — контроль другого шага для того же проекта.

Все файлы — расчётные данные, не исходные измерения. Процент по весам экспликации отличается от простого процента нарисованной маски. Незаданные параметры, неизвестное помещение 89 и неопределённые контуры не скрываются.
