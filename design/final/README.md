# Геометрия и текущая схема

Подложка извлечена из оригинального DWG; INSUNITS = 4 (миллиметры), координаты переведены в метры без подгонки площади. Модель визуально сопоставлена с исходным PNG. DXF-производная, созданная во временном каталоге, прочитана ezdxf: AC1027, 792 объекта model space, ошибок аудита — 0.

Для повторного извлечения использовать LibreDWG с исправленной обработкой handles
(0.13.4 или совместимую исправленную сборку); затем из корня репозитория:

```sh
dwgread -O JSON -o /tmp/floor.json 'docs/final/source-materials/Планировка первого этажа.dwg'
python scripts/final/extract_cad.py /tmp/floor.json
```

Для обычной пересборки сохранённой геометрии достаточно, конвертер не требуется.

`cad-geometry.json` — выбранные слои геометрии и тексты; декоративные линии опущены. Дуги на визуальной подложке аппроксимированы 32 отрезками; bulges полилиний показаны хордами, ellipses/splines не отображаются. Это не полноценный CAD-экспорт и не полная модель стен. Скрипт проверяет единицы и отсутствие повторяющихся handles. Строки с ошибочным кодированием символа м² в стороннем JSON не используются для геометрии; числовые площади читаются отдельно.

`room-schedule.csv` — 46 строк экспликации. Итог в чертеже 2097,06 м²; сумма округлённых строк 2097,08 м². У помещения 89 (45,52 м²) нет найденной метки в model space. Метки — позиции текста, не гарантированные центроиды помещения. Обозначение ВК не найдено; координата источника на проекте является предложением, не фактом задания.

Дополнительно сохранены витрины A-GLAZ-CWMG, дверные рамы, линии пола A-FLOR и исходные центры/радиусы дуг. Слой 0 внутри блока наследует слой вставки. Эти классы используются отдельно для восстановления площади и для радиопрепятствий; линии пола не объявляются стенами.
