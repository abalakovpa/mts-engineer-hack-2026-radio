# Карточка защиты допущений

Сначала назвать источник числа, затем объяснить его применение и границу результата.

| Вопрос | Короткий ответ для защиты |
| --- | --- |
| Почему 25 → 2 → 1? | Новые доли RRC/buffer снижают спрос до 13 UE. Старое k=1,10 даёт два сектора; для единственного общего пула принято k(1)=1. Это отдельное изменение допущения. |
| Откуда η=3,1505922? | Сетка PRB × CQI-эквивалент 6×567/1024 × средний rank 1,6 × доли RE, HARQ и заголовков. Коэффициенты сохранены из онлайн-модели. |
| Один сектор имеет запас? | Суммарно 113,42 Мбит/с против 104, но остатки распределены по полосам. Без CA вместимость ровно 13 UE. Средняя нагрузка не задаёт пик. |
| Что означает пилот 23 дБм? | В P1 — сумма CRS-поднесущих одного порта. P2 — альтернативная трактовка всей несущей, при которой RSRP не проходит 95%. |
| Чем SINR отличается от RSRQ? | SINR модели — βS/J для одного разделённого потока. RSRQ — N_RB×RSRP/RSSI, включая сигнал обоих TX-портов. |
| Где взяты NF, β, ρ и помехи? | Это явно заданные сценарии. L2: 7 дБ; 0,5; 0,8; −115 дБм/15 кГц. Исходники не задают эти характеристики. |
| Почему нельзя взять β=1? | При двух портах и ρ=0,8 предел RSRQ −12,25 дБ. Цель >−12 недостижима в этой модели даже без помех. |
| Как доказать допустимые помехи? | По взвешенным уровням площади и порогам. B7: I<−96,89 дБм/15 кГц при n=2,5; при n=3 — ниже −101,28. Это требования к условиям эксплуатации. |
| Как проверен DCS C/I? | Сравниваются поле BCCH и суммарная соканальная помеха в 200 кГц. При BCCH 40 дБм для 95% нужен I<−65,94 дБм. |
| Всё ТЗ выполнено? | Расчёты качества теперь представлены сценарно. UL, фактические настройки, комплектация и удалённое регулирование остаются отдельными условиями. |

## Репетиция перед защитой

1. Объяснить 360 → 126 → 13 → 104 без чтения текста.
2. Показать на схеме одну MIMO-ветвь и доли 1/4, 1/8, 1/16.
3. Повторить один RF-путь A28/B7 и различие контрольного уровня и покрытия площади.
4. Объяснить, почему второй TX-порт входит в RSSI, а другая антенна той же ячейки не становится новым сектором.
5. Ответить на вопросы о β=1, P2 и помехах −95 дБм без заявления о полном соответствии ТЗ.
6. Провести доклад с таймером: четыре минуты выступления, затем четыре минуты вопросов.
