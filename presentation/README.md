# Презентация и подготовка защиты

[Презентация](defense.pptx) содержит шесть редактируемых слайдов на
[официальном шаблоне МТС](source-template.pptx). Исходный шаблон сохранён
без изменения. Его градиент, логотипы и встроенные шрифты МТС используются
в итоговом файле.

[PDF для просмотра](defense-preview.pdf) получен из самого PPTX в LibreOffice.
[Обзор всех слайдов](slides-preview.png). Открытие в PowerPoint на компьютере
защиты и фактическая длительность выступления проверяются докладчиком.

## Содержание

1. Автор, образование и проектный опыт.
2. Новая модель спроса: 13 UE, 104 Мбит/с, один общий LTE-сектор.
3. Пассивная DAS: 32 In06, четыре группы, две MIMO-ветви.
4. RSRP, SINR, RSRQ и C/I: результаты явных сценариев и условия помех.
5. Оборудование, метраж кабелей и соединения.
6. Ключевые решения и технические условия результата.

[Текст выступления](speaker-script.md): 526 слов, план
25+40+55+55+35+30 = 240 секунд. Он сохранён отдельно для подготовки
и не включён в PPTX или архив для сдачи.

## Фото и личные сведения

Образование, III курс УрТИСИ, роли и вклад в Payment OCR / Magistral
Dispatcher MAX подтверждены автором. На первом слайде указано II место
на Всероссийском хакатоне связи в 2025 году.
Интересы — product management,
управление проектами и командная коммуникация. Источник текста —
[profile-input.json](profile-input.json).

На первом слайде размещена [фотография автора](assets/portrait.jpg),
полученная отдельным файлом. Исходный JPEG сохранён без изменения;
при вставке сохраняются пропорции изображения.

## Подготовка к защите

**[Короткий текст выступления — PDF](speech-cards.pdf):** шесть страниц,
по одной на слайд, с опорными числами. План — четыре минуты;
фактическое время проверяется репетицией. [Исходный текст](speech-cards.md).

**[Подробное руководство с нуля — PDF для iPhone](project-manual-iphone.pdf).**
Объясняет ёмкость, схему, RF-бюджет, карты, качество и оборудование;
содержит самопроверку с ответами и разбор шести слайдов.
Сохраняется для офлайн-чтения. Начать с маршрутов в первой главе.
Это отдельный учебный материал к отправленной версии, в конкурсный архив не входит.
[Текст руководства](project-manual.md).

1. Начать с [основ и маршрута подготовки](start-here.md), затем изучить
   [разбор решения](study-guide.md), повторить расчёт 13 UE и один RF-путь.
2. Разобрать [ответы жюри](jury-questions.md), найти основания в PDF/XLSX.
3. Разобрать [карточку допущений](assumptions-defense.md), затем отрепетировать доклад с таймером.
4. Проверить слайды на компьютере защиты; повторить отдельный текст выступления.
5. Готовиться по отправленной версии `submission-2026-10-14` и сохранить её локальную копию.

По сообщению автора, архив загружен на конкурсную платформу.
Проверенный файл совпадает с версией `submission-2026-10-14`.

## Пересборка

Для обучения и репетиции следующие команды не нужны. Они предназначены
для будущих изменений, которые не подменяют зафиксированный тег.

```sh
python scripts/final/final_presentation.py
python scripts/final/package_submission.py --include-presentation --reuse-technical
python scripts/final/validate.py
```

--reuse-technical сохраняет четыре готовых технических файла побайтно.
Требуется LibreOffice (soffice) для просмотра и проверки PPTX.
[Полная последовательность](../scripts/final/README.md).

Руководство пересобирается отдельно, не меняя решение для сдачи:

```sh
python scripts/final/build_learning_manual.py
```

Для него нужны ReportLab, PyMuPDF и DejaVu Sans, а также сохранённые
изображения проекта и `defense-preview.pdf`. Формат — узкая страница
340 × 756 pt; оглавление и закладки работают внутри файла без интернета.
