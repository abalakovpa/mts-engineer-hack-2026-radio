# Подготовка к защите

[Презентация](defense.pptx) содержит шесть редактируемых слайдов и текст
выступления в заметках. [PDF-предпросмотр](defense-preview.pdf) строится
по общему макету; это не результат открытия PPTX в PowerPoint.

1. Изучить [разбор решения](study-guide.md), повторить расчёт 13 UE и один RF-путь.
2. Прочитать [ответы жюри](jury-questions.md), найти подтверждения в PDF/XLSX.
3. Отрепетировать [текст выступления](speaker-script.md): 506 слов, план
   25+40+55+55+35+30 = 240 секунд. Проверить тайминг собственным выступлением.
4. Открыть PPTX на компьютере защиты, проверить шрифты, переносы и заметки.
5. Загрузить [пять артефактов](../submission/README.md) до 14.10.2026, 23:59 МСК.
