# Черновик защиты

`defense-draft.pptx` — шесть редактируемых слайдов с заметками выступающего; целевой тайминг 25+45+50+45+40+35 = 240 секунд. Свободный формат разрешён сообщением организаторов; после получения шаблона перенести содержание.

Сведения об авторе взяты из https://github.com/abalakovpa/abalakovpa (README на main, прочитан 12.10.2026): студент третьего курса УрТИСИ, специальность 11.03.02, II место во Всероссийском хакатоне связи 2025, ссылка на Svyaz Hack Payment OCR. Это утверждения профиля, а не независимая проверка достижений. Не добавлялись выдуманные обязанности или описание участия в проекте.

Перед окончательной защитой Павлу нужно подтвердить актуальность курса и указать текущую роль, собственный вклад в 1–2 проекта и профессиональные интересы. На первом слайде оставлено явное поле для дополнения.

Технические слайды показывают текущий рабочий статус и ограничения. Их нельзя переименовывать в «выполненные KPI» без завершения проверок; презентация пока не является готовой защитой окончательного решения.
