# Материалы защиты

Актуальная презентация — [defense.pptx](defense.pptx), шесть слайдов с заметками. PDF [defense-preview.pdf](defense-preview.pdf) создаётся по общему макету; это не рендеринг PowerPoint. Технические числа согласованы с итоговым проектом и включены в пакет submission. Роль, вклад и интересы остаются явными полями; актуальность курса требуется подтвердить. Редактируемые данные — [profile-input.json](profile-input.json).

[Текст выступления](speaker-script.md): 501 слов, план 25+40+55+55+35+30 = 240 секунд. [Ответы жюри](jury-questions.md) покрывают ёмкость, архитектуру, мощности, запас, метраж и несоответствия. Реальную репетицию с таймером выполняет автор.

## Ранее подготовленный черновик

`defense-draft.pptx` — шесть редактируемых слайдов с заметками выступающего; целевой тайминг 25+45+50+45+40+35 = 240 секунд. Свободный формат разрешён сообщением организаторов; после получения шаблона перенести содержание.

Сведения об авторе взяты из https://github.com/abalakovpa/abalakovpa (README на main, прочитан 12.10.2026): студент третьего курса УрТИСИ, специальность 11.03.02, II место во Всероссийском хакатоне связи 2025, ссылка на Svyaz Hack Payment OCR. Это утверждения профиля, а не независимая проверка достижений. Не добавлялись выдуманные обязанности или описание участия в проекте.

Перед окончательной защитой Павлу нужно подтвердить актуальность курса и указать текущую роль, собственный вклад в 1–2 проекта и профессиональные интересы. На первом слайде оставлено явное поле для дополнения.

defense-draft.pptx сохраняется как прежний генерируемый черновик. Для сдачи используется defense.pptx. Номинальная модель проходит RSRP, но фактические KPI и полное соответствие ТЗ не заявлены; это отражено в технических слайдах актуальной версии.
